Here is the "Quick Start" script. You can copy this entire block and run it in your VS Code terminal (make sure you are inside your project folder).

### **1. The "All-in-One" Setup Script**

Run these commands one by one:

```bash
# --- 1. SETUP FOLDERS ---
mkdir static templates static/css static/js static/images

# --- 2. CREATE STARTER FILES ---
touch app.py templates/index.html static/css/style.css static/js/main.js .gitignore

# --- 3. CONFIGURE VIRTUAL ENVIRONMENT ---
python -m venv .venv
# To activate:
# Windows: .venv\Scripts\activate
# Mac/Linux: source .venv/bin/activate

# --- 4. CONFIGURE GIT ---
echo ".venv/" >> .gitignore
echo "__pycache__/" >> .gitignore
git init
git add .
git commit -m "Initial structure setup"

# --- 5. CONNECT TO GITHUB (Replace URL with yours) ---
git branch -M main
git remote add origin https://github.com/YourUsername/YourRepoName.git
git push -u origin main

```

### **2. Essential "Daily" Commands**

Once set up, these are the only commands you really need to remember:

* **To Save Work:**
```bash
git add .
git commit -m "describe what you did"
git push

```


* **To Install a Library (e.g., Flask):**
```bash
pip install flask
pip freeze > requirements.txt

```

### **3. Your Project Structure Now**

Your VS Code sidebar should now look like this:

* **`.venv/`** (Python isolation)
* **`static/`** (CSS/JS/Images)
* **`templates/`** (HTML)
* **`app.py`** (Python Backend)
* **`.gitignore`** (Git settings)
